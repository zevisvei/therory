# תרגול תאוריה (Theory Practice)

פרויקט זה הוא אפליקציה לתרגול שאלות תאוריה שנכתבה ב-Python באמצעות Flet.

## דרישות מוקדמות

לפני תחילת העבודה, וודא שמותקנים אצלך הכלים הבאים:
- **Python**: גרסה 3.14 ומעלה (כפי שמוגדר בפרויקט).
- **uv**: מנהל חבילות ופרויקטים מהיר מאוד לפייתון.

### התקנת uv (אם לא מותקן)

אם `uv` עדיין לא מותקן אצלך, ניתן להתקין אותו באמצעות הפקודה (ב-PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

או ב-macOS/Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## התקנת תלויות

הפרויקט מנוהל באמצעות `uv`. כדי להתקין את כל הספריות הנדרשות (כמו `flet`), הרץ את הפקודה הבאה בטרמינל בתוך תיקיית הפרויקט:

```bash
uv sync
```

פקודה זו תיצור סביבה וירטואלית (virtual environment) ותתקין בתוכה את כל התלויות המוגדרות בקובץ `pyproject.toml`.

## הרצת האפליקציה

כדי להפעיל את האפליקציה, השתמש בפקודה `uv run` שמריצה את הסקריפט מתוך הסביבה הוירטואלית:

```bash
uv run main.py
```

### שמירת ניקוד

הכול נשמר ב-`localStorage` של הדפדפן תחת המפתח `maslul.v1` — XP ורמות, שיא לכל
תרגול, רצף ימי תרגול, תגים והיסטוריית סבבים. אין שרת ואין מסד נתונים בזמן ריצה.

### ייצוא הנתונים

האתר סטטי, ולכן השאלות והתמונות נצרבות מראש מ-`questions.db` לקבצים ב-`web/data/`:

```bash
python scripts/export_web.py
```

הסקריפט כותב את `web/data/questions.json`, את `web/data/meta.json` ואת תמונות
ה-WebP ל-`web/data/img/`. יש להריץ אותו מחדש בכל שינוי ב-`questions.db`.

### הרצה מקומית

```bash
python -m http.server 8000 --directory web
```

ואז לפתוח את http://localhost:8000

### הפעלת GitHub Pages

בפעם הראשונה יש לוודא ב-**Settings → Pages** שה-**Source** מוגדר ל-**GitHub Actions**.
לאחר מכן כל דחיפה ל-`main` מפרסמת מחדש.

## בניית קובץ הרצה (exe)

```bash
pyinstaller main.spec --noconfirm
```

ה-spec אורז את הלקוח הנייטיב של Flet (`flet_desktop/app/flet/`) — בלעדיו קובץ
ההרצה נסגר בשקט מיד עם ההפעלה. הבנייה מחייבת שהחבילה `flet-desktop` תהיה מותקנת
באותה סביבת פייתון שממנה מריצים את `pyinstaller`.

היסטוריית המבחנים של המשתמש נשמרת ב-`%LOCALAPPDATA%\TheoryQuiz\theory_quiz.db`,
מפני שתיקיית הפריסה הזמנית של PyInstaller נמחקת בכל יציאה מהתוכנה.
