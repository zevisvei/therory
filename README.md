# תרגול תאוריה (Theory Practice)

פרויקט זה הוא אפליקציה לתרגול שאלות תאוריה שנכתבה ב-Python באמצעות Flet.

## דרישות מוקדמות

לפני תחילת העבודה, וודא שמותקנים אצלך הכלים הבאים:
- **Python**: גרסה 3.14 ומעלה (כפי שמוגדר בפרויקט).
- **uv**: מנהל חבילות ופרויקטים מהיר מאוד לפייתון.

### התקנת uv (אם לא מותקן)

אם `uv` עדיין לא מותקן אצלך, ניתן להתקין אותו באמצעות הפקודה (ב-PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

או ב-macOS/Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## התקנת תלויות

הפרויקט מנוהל באמצעות `uv`. כדי להתקין את כל הספריות הנדרשות (כמו `flet`), הרץ את הפקודה הבאה בטרמינל בתוך תיקיית הפרויקט:

```bash
uv sync
```

פקודה זו תיצור סביבה וירטואלית (virtual environment) ותתקין בתוכה את כל התלויות המוגדרות בקובץ `pyproject.toml`.

## הרצת האפליקציה

כדי להפעיל את האפליקציה, השתמש בפקודה `uv run` שמריצה את הסקריפט מתוך הסביבה הוירטואלית:

```bash
uv run main.py
```
